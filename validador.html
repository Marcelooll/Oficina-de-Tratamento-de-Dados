Passo a Passo de Resolução (Linha por Linha)

Objetivo do Desafio 1: Limpar e padronizar os e-mails dos inscritos para o envio de convites do evento. Siga as linhas abaixo no seu script Python:
Passo 1 • Importar a Biblioteca
import pandas as pd
🔍 O que essa linha faz: Carrega a biblioteca Pandas no Python e dá a ela o apelido pd para facilitar a escrita no código.
💡 Por que fazemos isso? O Python básico não possui comandos nativos para manipular tabelas inteiras de uma só vez. O Pandas cria o "DataFrame", que funciona como uma super planilha inteligente.
Passo 2 • Carregar o Arquivo Bruto
df = pd.read_csv("desafio1/emails_brutos.csv")
🔍 O que essa linha faz: Abre o arquivo CSV com os dados não tratados e guarda todas as linhas e colunas dentro da variável df.
💡 Por que fazemos isso? Para que o Python possa limpar os dados, eles precisam primeiro ser lidos do disco rígido e carregados na memória do computador.
Passo 3 • Preencher os E-mails em Branco
df["email"] = df["email"].fillna("email_nao_informado@dominio.com")
🔍 O que essa linha faz: O método .fillna(...) localiza todas as células vazias (ausentes / NaN) da coluna email e preenche com o texto especificado.
💡 Por que fazemos isso? Se tentarmos disparar convites para um campo vazio, o sistema de e-mails trava com erro. Usar um e-mail padrão evita a quebra do sistema e permite saber exatamente quantos alunos não informaram contato.
Passo 4 • Remover Espaços Extras nas Pontas
df["email"] = df["email"].str.strip()
🔍 O que essa linha faz: O comando .str.strip() remove espaços em branco acidentais digitados antes ou depois do e-mail (ex: " joao@email.com " vira "joao@email.com").
💡 Por que fazemos isso? Para o computador, um espaço faz parte do texto. Se o e-mail tiver um espaço no início ou fim, os servidores de e-mail rejeitam o envio por "endereço inválido".
Passo 5 • Padronizar em Letras Minúsculas
df["email"] = df["email"].str.lower()
🔍 O que essa linha faz: Transforma todas as letras da coluna email em letras minúsculas (ex: "MARIA@GMAIL.COM" vira "maria@gmail.com").
💡 Por que fazemos isso? Evita cadastros duplicados. Sem essa padronização, um banco de dados pode tratar "Ana@gmail.com" e "ANA@GMAIL.COM" como duas pessoas diferentes, disparando dois convites para o mesmo aluno.
Passo 6 • Salvar o Arquivo Tratado
df.to_csv("desafio1/tratado.csv", index=False)
🔍 O que essa linha faz: Grava a tabela limpa em um novo arquivo CSV. O parâmetro index=False impede que o Python crie uma coluna extra e desnecessária com os números das linhas (0, 1, 2...).
💡 Por que fazemos isso? Toda a limpeza feita no Python acontece apenas na memória temporária. Para entregar o resultado e validar aqui no site, precisamos salvar o arquivo final no disco!
Objetivo do Desafio 2: Tratar a planilha de gastos do churrasco, substituindo vírgulas por pontos decimais e convertendo texto para número para permitir a soma total.
Passo 1 • Importar a Biblioteca
import pandas as pd
🔍 O que essa linha faz: Carrega o Pandas para manipular as colunas numéricas da planilha de despesas.
💡 Por que fazemos isso? O Pandas nos permite transformar e converter colunas inteiras de uma vez só com facilidade.
Passo 2 • Carregar as Despesas
df = pd.read_csv("desafio2/despesas_churrasco.csv")
🔍 O que essa linha faz: Lê o arquivo onde os amigos anotaram o que compraram e quanto pagaram.
💡 Por que fazemos isso? Coloca a lista de despesas na memória do Python para podermos consertar os valores incorretos.
Passo 3 • Preencher os Valores Não Informados
df["valor"] = df["valor"].fillna("0.00")
🔍 O que essa linha faz: Preenche os amigos que não colocaram o valor com custo zero ("0.00").
💡 Por que fazemos isso? Em matemática computacional, qualquer número somado a um dado vazio (NaN) vira NaN. Se deixarmos campos em branco, a soma de todo o churrasco vai falhar!
Passo 4 • Substituir Vírgula por Ponto
df["valor"] = df["valor"].astype(str).str.replace(",", ".")
🔍 O que essa linha faz: Garante que os dados sejam texto e substitui a vírgula brasileira (,) pelo ponto decimal internacional (.) (ex: "145,90" vira "145.90").
💡 Por que fazemos isso? O Python foi criado no padrão americano, onde números decimais usam ponto. Se tentarmos transformar um texto com vírgula em número, o Python gera um erro de sintaxe.
Passo 5 • Converter para Número Decimal (Float)
df["valor"] = df["valor"].astype(float)
🔍 O que essa linha faz: Converte o tipo da coluna de texto (string) para número decimal (float).
💡 Por que fazemos isso? O computador não faz contas matemáticas com textos. Se somarmos "10" + "20" como texto, o resultado vira "1020"! Com float, o Python consegue somar o total real da festa (df["valor"].sum()).
Passo 6 • Salvar a Planilha Calculável
df.to_csv("desafio2/tratado.csv", index=False)
🔍 O que essa linha faz: Exporta os dados corrigidos para o arquivo desafio2/tratado.csv.
💡 Por que fazemos isso? Agora a tabela tem apenas números válidos e está pronta para ser dividida entre os amigos e validada no site!
Objetivo do Desafio 3: Padronizar cidades em maiúsculas e nomes em título para que o Python consiga identificar e eliminar participantes repetidos da lista de presença.
Passo 1 • Importar a Biblioteca
import pandas as pd
🔍 O que essa linha faz: Importa o Pandas para podermos analisar e limpar as linhas duplicadas.
💡 Por que fazemos isso? O Pandas possui funções extremamente rápidas de deduplicação que economizam horas de trabalho manual.
Passo 2 • Carregar a Lista de Presença
df = pd.read_csv("desafio3/lista_presenca.csv")
🔍 O que essa linha faz: Carrega o arquivo onde constam os nomes e as cidades dos inscritos.
💡 Por que fazemos isso? Coloca a lista na memória para localizarmos inscrições duplicadas feitas por engano.
Passo 3 • Padronizar Cidades em MAIÚSCULAS
df["cidade"] = df["cidade"].str.strip().str.upper()
🔍 O que essa linha faz: Remove espaços extras e converte o texto de todas as cidades para letras MAIÚSCULAS (ex: "são paulo" e " São Paulo " viram "SÃO PAULO").
💡 Por que fazemos isso? Se não padronizarmos a escrita antes, o computador vai achar que "são paulo" e "SÃO PAULO" são duas cidades diferentes e não vai conseguir remover as linhas duplicadas!
Passo 4 • Padronizar Nomes em Formato Título
df["nome"] = df["nome"].str.strip().str.title()
🔍 O que essa linha faz: O método .str.title() deixa a primeira letra de cada palavra maiúscula (ex: "lucas silva" vira "Lucas Silva").
💡 Por que fazemos isso? Padroniza nomes próprios para geração de certificados oficiais e relatórios sem erros de digitação.
Passo 5 • Eliminar Inscrições Duplicadas
df = df.drop_duplicates()
🔍 O que essa linha faz: Compara todas as linhas da tabela e apaga automaticamente aquelas que forem idênticas a um registro anterior.
💡 Por que fazemos isso? Alunos ansiosos costumam clicar duas vezes no botão de enviar formulário. O drop_duplicates() garante que cada aluno só seja contado uma única vez no evento e nos sorteios.
Passo 6 • Salvar a Lista Limpa de Participantes
df.to_csv("desafio3/tratado.csv", index=False)
🔍 O que essa linha faz: Salva a lista final com apenas os participantes únicos no arquivo desafio3/tratado.csv.
💡 Por que fazemos isso? Gera a base oficial para emissão de certificados e validação no site!
