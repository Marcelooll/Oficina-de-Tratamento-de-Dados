Conceitos Básicos

O que é uma Variável?
Uma variável é como uma "caixa" onde guardamos dados na memória do computador. No Python, criamos variáveis usando o sinal de igual =. Por exemplo, df = pd.read_csv(...) guarda a nossa tabela lida dentro da variável chamada "df" (Data Frame).

O que é um Tipo de Dado (Data Type)?
Computadores tratam textos e números de forma diferente.
- String: Texto (ex: "10,5" com aspas). Não é possível fazer contas matemáticas com ele.
- Float: Número decimal (ex: 10.5).
- Integer (Int): Número inteiro (ex: 10).
- Datetime: Formato especial para datas, permitindo calcular diferenças de dias ou extrair meses.

Passo a Passo dos Desafios

Desafio 1: Tratamento de Tipos (Obrigatório)

Objetivo: Consertar uma base onde valores financeiros foram lidos como texto devido ao uso de vírgula.

  1. Carregue o arquivo CSV. Dica: observe o separador usado no arquivo (ponto e vírgula).
  2. Identifique a coluna que contém o valor financeiro.
  3. Como o Python usa formato numérico americano, substitua as vírgulas por pontos nessa coluna.
  4. Converta o tipo de dado da coluna de texto (string) para decimal numérico (float).
  5. Salve o resultado como tratado.csv na pasta do desafio.

Comandos que você vai precisar:
pd.read_csv(arquivo, sep=";"), df['coluna'].str.replace(",", "."), df['coluna'].astype(float), df.to_csv(arquivo, index=False)

Desafio 2: Limpeza e Nulos (Extra)

Objetivo: Limpar o cabeçalho e tratar dados vazios de uma planilha do governo.

  1. Carregue a planilha .ods. Como não é um CSV, você precisará usar um leitor de excel.
  2. Padronize os nomes de todas as colunas: transforme tudo para letra minúscula e substitua os espaços em branco por underline (_).
  3. Exclua as linhas que vieram completamente vazias.
  4. Para os buracos restantes (dados nulos nas células), preencha-os com o valor zero.
  5. Exporte como tratado.csv.

Comandos que você vai precisar:
pd.read_excel(arquivo, engine="odf"), df.columns.str.lower(), df.columns.str.replace(" ", "_"), df.dropna(how="all"), df.fillna(0)

Desafio 3: Extração de Binários (Extra)

Objetivo: Vasculhar arquivos de assinatura (p7s) e extrair metadados.

  1. Use o módulo glob do Python para listar todos os arquivos .p7s da pasta.
  2. Para cada arquivo encontrado, abra-o no modo leitura binária e leia seu conteúdo.
  3. Extraia o nome do remetente (que está no nome do arquivo) e extraia/crie uma chave hash do arquivo.
  4. Junte essas informações em uma lista e converta para uma Tabela (DataFrame).
  5. Verifique se há linhas duplicadas e remova-as, garantindo que nenhum arquivo foi processado duas vezes.
  6. Exporte o resultado.

import glob, glob.glob("*.p7s"), with open(arquivo, "rb") as f:, pd.DataFrame(lista), df.drop_duplicates()
